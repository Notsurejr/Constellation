Diagnostics

The app quietly records performance data while it runs — memory, slow frames, scroll movements, keystroke rate (counts only, never what you type), and how long the heavy steps take. If something stutters, jumps, or flares: click this right after it happens, and a text file with the evidence is written to the app data folder. Nothing is sent anywhere; the file is yours to read or share.

Connection global

Each connection = endpoint + its models + a key. Save connection stores everything shown — including the key (blank keeps the stored one). Keys live in config\keys.json, encrypted with Windows' credential protection (DPAPI); they never leave this machine and never enter backups. Chats route through whichever connection offers their model — the default row only decides where unknown/Custom models go.
